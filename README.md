## 盲注结构与 rebuy
大家可以在 structure 栏查看盲注结构。结构有所改动，升盲速度减慢了：每人起始筹码 2000，blind level 1 为 5/10（200bb）。

开赛后的前 72 分钟（blind level 12），每人在被清台时可以 rebuy，至多 2 次，每次仍为 2000 筹码。

比方说，@小罐茶🍵 在 blind level 7（20/40）一手 KK 被我 AA 吃光了并选择 rebuy，则将以 2000 筹码＝50bb 继续上桌。

之后每 6 分钟升一次盲，没有 straddle，但有 ante，每次行动限时 20 秒。越往后，升盲速度会越快，全程预计在 2 小时左右完成。

## 切换为 BB 显示
随着盲注提升以及 rebuy 越来越多，整体均码数会不断增加，open／raise／3b／4b 时选择下注数量可能会不方便。大家可以将后手和底池数切换成大盲数，精确到小数点后两位。

操作路径：左上角 options → preference → value display style → BB。

切换成 BB 数之后，若要下注 2.5bb，需要输入 250；输入 2500 则对应 25.00bb。

## 关于奖池
初始买入以及前 72 分钟内的每一次 rebuy，均为 40 RMB。每个 buy-in 分为 20 RMB 基本奖金＋20 RMB 神秘赏金。

基本奖金与以往标准 tournament 奖金处理方式相同：按照最终锦标赛排名发放。

## 关于神秘赏金
N 个 Entry 准备 N 份神秘赏金。金额从高到低称为超级大奖、一等奖、二等奖、三等奖。超级大奖 1 份，一等奖最多 2 份。

每产生一个淘汰，由收下该人头的获奖者领取一次抽赏名额；同一玩家拿下多个人头，可获得多个名额。前 N−1 份用于人头奖励，最后剩下的一份归最终冠军。
